# StateTune缺陷盘点与标注准备

本轮没有新模型调用、训练更新或生产变更。统计的是历史v10全部36题、2391次模型调用。只读旧原文，不把失败输出自动改成正确答案。

- [统计汇总](SUMMARY.json)：731条失败记录、726个可关联的失败模型调用；5条无模型调用的执行记录单列。按错误和逐字材料合并为113组待标注任务。
- [完整失败与标注任务](diagnosis-and-annotation-jobs.tar.gz)：包含FAILURES.jsonl、ANNOTATION-JOBS.jsonl、汇总、输入哈希和8份诊断范例。没有正式训练数据导出。
- [8份校正范例](DIAGNOSTIC-EXAMPLES.jsonl)：原始prompt、错误输出、显式标注目标及原因分别保留。实现者审读，非独立复核，标记diagnostic_only，不能计作未见留出或自动训练。
- [历史输入哈希](SOURCE-PINS.json) · [归档成员哈希](ARCHIVE-SHA256.json) · [实现与标注版本](IMPLEMENTATION-PINS.json)。打包后逐成员校验通过，历史输入哈希未变。

最集中的两种校验失败是引文不逐字397次、范围不逐字226次。它们共623条，占731条失败记录的85.2%，不等于题目错误率。226条范围错误中101条scope等于标题、11条等于对象名；129条value逐字存在仍不能当作正确事实，字段/对象也可能错。

6项统计与去重保护测试通过；5份原子范例通过现有结构/逐字/数值校验。程序检查不等于语义验收。详细口径、后续按缺陷扩展和分集规则见[数据方案](../../llamaindex-retrieval/statetune/defect-led-20260922/README.md)。
