# 根据真实失败纠错种子生成的2000条数据

当前版本：`draft-v6-seeded`，训练数据包：`release-v1/INDEX.json`。六组训练已完成，结果见项目 docs/statetune-experience.md。

先保留真实调用的完整输入、证据与错误输出，再依据当时该阶段可见的材料写正确输出。17条种子已独立逐条批准，详见 `correction-seeds-v1/README.md`。错误输出只作审计记录，模型监督目标只有正确输出与EOS。

2000条派生数据已独立复核并分阶段打包：Writer1400、Reader450、Planner150。Writer另有嵌套100/300/600条子集，用于后续同参数规模比较；这些子集不额外计入2000条。三种输出协议分别保留，不能混合训练成一个state。

每条派生数据记录父纠错种子、原trace哈希、正确目标哈希和实际构造场景。774条输入重新构造，1226条沿用已复核的受控实例；它们不是2000条自然发生的新问题。父种子设计指导不意味着每个子例实现所有指导项。

复核文件：`SEEDED-INDEPENDENT-REVIEW.json`。这是主代理对独立审查结果的转录，不是认证签名。六个训练包的目标字节、mask、EOS、哈希和子集包含关系检查见 `RELEASE-CPU-VALIDATION.json`。

旧题及其纠错种子属于已暴露开发材料，不能再作为盲测；原实验分数保持原样。训练真实来源313页，与保留的200条通用回归数据所用30页隔离。另需独立trace缺陷挑战集和真实2.9B端到端测试，才能判断改善幅度和训练极限。
