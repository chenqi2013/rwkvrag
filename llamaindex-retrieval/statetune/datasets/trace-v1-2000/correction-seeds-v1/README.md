# 真实失败调用的纠错种子

17条已由独立审查代理逐条批准。保留原始输入和原错误输出，只将正确输出作为生成种子的目标。

这些旧题已暴露，属于开发材料；原测试分数不改写，未来不能把它们称作盲测。2000条派生草稿需要独立审查。

## correction_pump_citations

阶段：writer。 A款2023与B款2023引用错绑；保留正确事实，逐事实绑定真正来源。

正确输出：

```text
A款2022年：额定流量8 L/min，不能离线运行。[资料 1]
A款2023年：额定流量6 L/min，支持离线运行。[资料 1]
B款2023年：额定质量流量4 kg/min，不能离线运行。[资料 2]
```

生成时保留：同对象不同年份与不同对象同时出现；来源顺序和问题顺序独立变化，包括首答案引用1；单位不换算。

## correction_reef_dates

阶段：writer。 完整表格已可见；按结局筛选两行，绑定置放日期，不取退役或下水日期。

正确输出：

```text
红山毛榉号：2000年6月10日置放为人工鱼礁。[资料 1]
红橡号：1999年9月13日置放为人工鱼礁。[资料 1]
```

生成时保留：保留完整行列和竞争日期；匹配行数与行顺序变化；目标和干扰日期年份交叠，不能凭年份筛选。

## correction_release_reference_date

阶段：writer。 资料3的2015-04-03是参考文献日期；上映事实在资料2。

正确输出：

```text
《殺手少女》真人电影于2015年4月11日在日本上映。[资料 2]
```

生成时保留：同一对象同时有事件日期与参考文献日期；保留标题和事件语义；随机化日期先后及引用位置。

## correction_can_units

阶段：writer。 64字节不能写成64位；速率和线路条件分别取支持证据。

正确输出：

```text
消息ID支持11位和29位。[资料 1]
每帧最大实际数据量为64字节（byte）。[资料 2]
条目给出的最高资料率为5 Mbit/s。[资料 2]
可达的最高速率受电气条件和组态影响，包括节点个数、总线长度及其他电磁因素。[资料 1]
```

生成时保留：位与字节出现在同一主题；保留速率适用条件；禁止跨字段挪用数值。

## correction_fee_scope

阶段：writer。 原输出遗漏一半和不应一刀切剔除的限定，不能改成全额豁免。

正确输出：

```text
卢伟国建议豁免自修生一半考试费，认为这已足够杜绝捣乱，不应一刀切将自修生从计划中剔除。[资料 3]
```

生成时保留：保留分数、否定及适用对象；同主题对照全额与部分；建议不能写成已执行政策。

## correction_missing_score

阶段：writer。 奖牌与赛事资料不能支持决赛比分，删去编造比分与引用。

正确输出：

```text
所给资料未提供仲满男子个人佩剑决赛的最终比分，无法据此确定。
```

生成时保留：保留相关但不含所求事实的资料；缺失判断覆盖全部可见证据。

## correction_planned_not_actual

阶段：writer。 计划派发数量不等于实际使用数量。

正确输出：

```text
所给资料记载的是计划派发一万张门票。[资料 1]
未提供最后实际使用的张数，无法据此确定实际使用量。
```

生成时保留：保留诱人的计划数；目标明确区分计划与实绩；增加实际数可见的正例对照。

## correction_aggregate_not_each

阶段：writer。 整体计划预算不能当作每个街市的拨款。

正确输出：

```text
资料只说明预留20亿元在未来十年推行街市现代化计划。[资料 2]
未提供每个街市分别获拨的金额，无法据此列出各街市资金。
```

生成时保留：总额与每对象金额区分；不得平均分摊推算未给出的分项。

## correction_empty

阶段：writer。 空证据不能生成日期、场馆或虚构资料编号。

正确输出：

```text
当前没有可用证据，无法据此确定所问日期和场馆。
```

生成时保留：真正空证据；只说明当前依据不足，不声称现实不存在。

## correction_train_multipart

阶段：writer。 三个问题分别作答，不能用重联方式替代编组总数和动力车数。

正确输出：

```text
ICE-1不能与其他列车组合运行，只能单独运行。[资料 1]
ICE-2科隆／杜塞尔多夫往柏林的例子在Hamm站合体。[资料 5]
JR九州305系每编组共6辆，其中4辆为动力车。[资料 8]
```

生成时保留：多对象多字段同时保留；每一子问题都要覆盖；相近概念证据作为干扰。

## correction_history_active

阶段：writer。 按完整历史保留最终三格，不恢复3.51、Server版或已删除协议背景。

正确输出：

```text
Windows NT 3.5工作站版允许10个客户端并发访问文件服务器。[资料 1]
不支持Mac客户端。[资料 1]
开发代号为Daytona。[资料 1]
```

生成时保留：保留真实长历史中的分散更正；最新问题依赖指代；保留要求与撤回要求交错，不能只依赖全部撤回模板。

## correction_stop_after_answer

阶段：writer。 首个结论已经正确，删除循环复述，完整答案后训练EOS。

正确输出：

```text
乌鲁伊在昆士兰州艾尔利海滩附近登陆。[资料 3]
```

生成时保留：保留大段干扰证据；短目标覆盖完整有效问题；EOS进入监督标签。

## correction_writer_partial_after_reader

阶段：writer。 Writer实际仅看到两份证据；Reader另两份虽有答案，但没有进入这个调用，不能倒灌为Writer目标。

正确输出：

```text
IEC 61131-3条目列出的五种语言是指令表（ILD）、阶梯图（LD）、功能区块图（FBD）、结构化文字（STL）和顺序功能流程图（SFC）。[资料 2]
IEC 61499以事件驱动模型取代循环执行模型。[资料 1]
当前所给证据未提供DLMS三份规范文档的书籍颜色，也未提供IEC 61508安全生命周期的阶段数，无法据此确定这两项。
```

生成时保留：部分问题有证据、部分没有；严格按当前阶段可见证据纠错；禁止用完整语料替代当前输入边界。

## correction_planner_history

阶段：planner。 原输出7条queries越界且复制历史；压缩为涵盖当前有效要求的两条检索式，不填答案。

正确输出：

```text
{"queries": ["Windows NT 3.5 工作站版 文件服务器 并发客户端上限 Mac客户端支持", "Windows NT 3.5 开发代号"], "fields": ["Windows NT 3.5工作站版允许的并发文件访问客户端数", "Windows NT 3.5工作站版是否支持Mac客户端", "Windows NT 3.5开发代号"]}
```

生成时保留：输出1至6条必要且不同检索式；有效要求不能因压缩丢失；撤回对象不进入检索。
