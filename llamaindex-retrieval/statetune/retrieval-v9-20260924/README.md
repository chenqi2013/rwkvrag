# 检索 StateTune V9：待审读数据选择

[SELECTED-IDS.json](SELECTED-IDS.json)按固定哈希引用 [V8 完整候选池](../retrieval-v8-20260924/CANDIDATES.jsonl)，选出 **5,462 条**待审读数据：规划 2,400、单格证据 2,034、补查/停止 1,028。完整行在 V8 候选池，ID 清单避免再复制 17 MB 文本。[AUDIT.json](AUDIT.json)记录 token、来源、题型和准入检查；[重放核验器](../../../scripts/retrieval_statetune/verify_review_queue_v9.py)逐行重新验证来源字节、引文、目标、分集、旧题禁入、token mask/EOS 和哈希。

本轮按用户要求只准备数据，未训练、未切正式模型或检索服务。真正训练前需要独立复核比较正例和高风险负例、补真实同范围冲突及冻结新盲题；不能仅凭这里的数量和逐字跨度宣布质量提升。详细边界见[当日报告](../../../docs/archive/2026-09/retrieval-dataset-v9-20260924.md)。
