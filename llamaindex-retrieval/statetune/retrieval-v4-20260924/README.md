## 盲题与自然问法

[V3 盲题草稿](../retrieval-v3-20260924/BLIND-CANDIDATES.jsonl)有 127 条结构候选，但 15 条 `missing` 没有明确缺口要求、16 条 `conflict` 没有明确同项目同版本范围，因此**120 题盲集尚未冻结**。这些仓库族与训练族分离；来源分离并不替代逐题质量审读。

为减少“把维度列表强写进问题”，另做了同 12 组任务的问法先行试点：V5 结构绑定 24/96，V6 允许每题只使用确实提到的候选项目后为 65/96。[V6 原文候选](../retrieval-v6-20260924/PILOT-CANDIDATES.jsonl)仍有类别错配、历史轮次缺失和额外项目简称，未独立审读，不能用作训练或盲测。V5 与 V6 同时改变提示词和项目绑定规则，不能单变量归因。
