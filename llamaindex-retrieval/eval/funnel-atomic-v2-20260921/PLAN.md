# 单对象单字段原子层v2

v1在原子提取中仍把全部对象×字段放进同一次调用，实测出现重复展开、触顶、字段错配。v2不再这样做：先由模型选择每份来源涉及的对象，再让每次原子提取只看一个对象、一个字段、一份原文；之后同对象同字段核验→同维度汇总→Writer。TaskSpec约束新增用户原话绑定，防止把提示指令误当用户约束。

使用v1相同的36条固定材料（完整自然8+旧28），所有失败与旧题保留。模型、State、引擎、tokenizer、解码参数不变。原子节点512，来源对象节点128，合计调用上限512。结构与预算是整个v2协议包，不做单句因果归因。无联网调用，不宣称端到端已修复。
