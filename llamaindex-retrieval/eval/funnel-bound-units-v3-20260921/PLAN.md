# 漏斗v3：绑定原文单元，隔离调试元数据

v2定位到原子任务已拆小但quote复制会丢换行、来源对象O编号混淆，完整外层Markdown代码围栏导致格式拒绝；最终Writer还收到了长source_id/hash/offset/异常调试图，重新撑大输入。这些是协议与实现问题。

新协议：来源路由返回原样对象名称；原子节点返回value及已给出的E编号，代码按ID取逐字原文，不让模型复制或拼接quote；模型仍决定语义选择。允许完整外层JSON代码围栏作为格式解析，禁止从解释文字中猜JSON、禁止修改模型原始输出。核验每格最多引用4个fact，最终只投影核验值、来源标签、同维度小结及来源原文，原始调用/错误/哈希/位置仍在trace而不再喂给Writer。仅同来源同原文的重复quote去重，不合并不同来源冲突。

整个v3协议包为候选，沿用同36条完整固定材料、同7.2B零State/引擎/greedy/seed和输出2048。单源对象128、原子384、核验512、关系768，总调用上限512。门槛及非独立审读声明沿用v2；未通过不部署正式服务。不是实时联网复验，也不把代码校验等同语义正确。
