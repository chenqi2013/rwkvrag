# 全题型回归与历史题目保留

来源：用户于 2026-09-20 明确要求“大量测，各种类型都要”，不能为了冲突问题关闭或删除之前的题目。本页约束后续实验与接入；实际执行状态见 [CURRENT](CURRENT.md)。

## 保留规则

1. 已有题库、原始问题、金标、历史结果和失败记录保留。新增题目采用新文件或新版本，不覆盖旧题。
2. 不因模型答错、耗时、缺引用、格式失败或接口不支持而关闭题目、修改标签或移出分母。
3. 同一题出现在多份历史题库中时，保留来源成员关系，同时明确报告去重后的题数；不能把重复题或多轮调用算成新的独立样本。
4. 发现题目歧义或标注错误时，保留原题和原分数，另建修订版本并记录理由、关联 ID 及不同口径。不能在看到输出后静默改成答对。
5. 尚未执行、接口不支持、依赖不可用、运行失败、格式无效、语义错误分别记录。未执行不等于通过，也不删除执行入口。

## 覆盖与接入门槛

普通事实、定义、人物/机构、时间、地点、数值、单位、列表、步骤、原因、明确否定、零值与未记载、表格、适用范围、修订、对比、冲突、多语言及真实检索均需要对应记录。对话历史与最终引用的验收属于完整问答，不能只用二元 Reader 题代表。

任何候选变更必须列出基线正确而候选错误的旧题 ID，并分别报告每个题库与题型。冲突、表格或总体平均分的改善不能抵消普通题的退步。整体门槛还需检查误选、非法输出、漏答、引用和运行成本。

语义准确率、引用支持关系与自动词项命中诊断分开报告。检索到了正确标题、输出了引用编号或 HTTP 返回 200，都不能单独证明回答正确。
