## 已完成

1. **修复规划失败被计为完成的问题。** Planner 失败后仍可按原问题检索并保留模型回答，但成功返回 Writer 后，整链路标记 `planner_partial_failure`，历史归类 `partial`。新增 `stage_status` 和 `planner_fallback`，保留复合失败信息。Writer 截断/超时优先保留，Resolver 失败仍按原状态显示。
2. **拒绝有歧义的 Planner JSON。** 重复键不再被后一个值静默覆盖；按格式错误处理，并保留原输出和解析错误。
3. **新增固定材料质量验收入口。** 复用已有 smoke 数据与收据，固定 8 题分母，核对源码、输入、输出哈希；将调用完成、正文协议、引用编号存在性与显式语义复核分开。未复核不能通过，错误与截断不能从分母消失。
4. **跑完一轮真实 2.9B Writer300 基线并逐题复核。** 模型调用与原始答案全部保存；复核未修改金标或模型文本。

入口与使用方法：[QUALITY_GATE.md](../../../llamaindex-retrieval/eval/native-smoke/QUALITY_GATE.md)。

## 结果

**8/8 执行完成，3/8 通过本组全部质量要求，验收退出码为 1（失败）。**

| 指标（以题为单位） | 通过 / 已评 | 说明 |
| --- | --- | --- |
| 执行完成 | 8/8 | 不代表答案正确 |
| 原文与正文协议有效 | 8/8 | 原始输出保留、正文边界与模型字段符合声明 |
| 引用编号有来源 | 7/8 | 只检查编号存在，不检查事实支持；没有引用也不能由此判为有据 |
| 全部必要事实正确完整 | 4/7 | 无正向事实的拒答题不计入此项已评分母 |
| 全部必要事实引用受支持 | 3/7 | 错引和缺引用都失败 |
| 回答/拒答决策正确 | 7/8 | 与事实完整性独立统计 |
| 没有无据主张 | 5/8 | 包含额外解释与杜撰值 |
| 全部质量条件通过 | 3/8 | 全题组分母保持为 8 |

复核由本任务主代理依据冻结 gold、完整历史和原文完成，**不是第二位独立审核者的复核**。这是已暴露的固定材料开发题组，不是完整 RAG、新盲测、全场景准确率或 Writer300 与零 state 的公平对照。
