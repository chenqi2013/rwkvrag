# 当前知识添加方式核查

## 日常文件

打开正式前端 http://localhost:18440/admin/#/knowledge-bases 创建/选择知识库，再到 http://localhost:18440/admin/#/files 选择对应知识库，拖入或多选文件。支持.md/.markdown/.mdx、文本PDF和DOCX，单文件上限100MB。后台异步解析、切片、建立OpenSearch BM25索引；到“导入任务”查看完成或失败，再在检索页选择该库提问。上传成功不等于索引已就绪。

扫描PDF目前必须先OCR。DOCX表格以行文本解析，复杂结构不等于可靠保留。当前上传入口不直接支持普通TXT、CSV、Excel或图片。更新文档通过“上传新版本”入口；不要直接改写服务端已登记原文件。

## 批量语料

前端“导入任务”可选择服务端允许目录内的FineWiki/Parquet文件或目录，指定知识库、数量上限、批大小，创建异步任务。当前允许根目录为/home/chase/GitHub/rwkvrag/data/corpora。普通追加保持recreate=false；重建是整体索引替换操作，不是日常追加。路径指后端能访问的路径，不是浏览器电脑随意输入的路径。

另有POST /v1/import/markdown目录接口，递归读取服务端.md/.markdown，默认批16；该接口直接写索引，默认知识库，管理文件登记、修订和Wiki任务流程不同于上传入口，不建议作为普通用户日常管理入口。不是监控文件夹自动同步。

## 实际状态与规模边界

正式健康接口实测OpenSearch green、46,051条检索切片，16个知识库，任务列表19个completed。切片数不是原文篇数，也不证明所有任务内容质量。浏览器实测生产上传页存在、多选开启、类型限制和100MB提示可见；没有实际上传资料。

当前代码：单文件任务批8、默认2工作任务，OpenSearch批写500；并不等于可无限并发。文件入库/修订路径为新建索引版本、复制其他已有文档、加入本文件后切换别名，旧知识保留。这意味着大量小文件逐个上传会重复复制索引；索引写锁冲突会失败返回，而不是自动排队等待。没有本轮大规模吞吐或百万篇验收，不能保证任意规模快速导入。

因此可按知识库分批添加，批量语料可用一个FineWiki任务分批写入；“多选上传”不是成熟的海量导入调度。添加资料是更新检索索引，不是训练RWKV参数。配置中的wiki_auto_generate=true表示文件索引后可排队生成来源绑定草稿，不等于草稿正确或全部语料自动形成成熟Wiki。
