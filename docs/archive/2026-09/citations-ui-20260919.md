## 修复的问题

旧页面将答案中的引用编号显示为普通文本，无法点击；历史证据受 48px 高度限制且没有展开入口；本地文档链接直接使用 file://，浏览器无法打开。用户不能顺畅核对回答原文。

三个页面现在共用 CitedAnswer：

- 点击 [资料 N]、[Source N] 或数字引用即可打开引用原文侧栏，也支持键盘 Enter。
- 来源卡片明确显示编号、标题、来源类型，提供展开原文及“查看完整引用”按钮。
- 历史表格增加“查看引用”入口，展开后展示各次运行保存的来源。Wiki 使用当前选定版本的来源。
- 侧栏直接显示回答使用的逐字证据，可复制；有记录时可展开文档上下文和当时保存的网页材料。
- 网页显示可打开的 HTTP(S) 来源链接及已保存的日期；本地文档直接显示历史保存的证据，不再提供失效的 file:// 跳转。
- 存在 citation_map 时严格按 ID 映射，不用来源列表位置替代缺失映射。未知编号明确显示无对应来源；不修补或重编号模型引用。
- 正文复制保留原始显示文本。HTML、脚本以及来源材料均作为文本展示。

本次解决“看不到引用内容”的展示问题，不宣称修复了模型引用错位或事实归属问题；页面保留未做语义核验的提示。
