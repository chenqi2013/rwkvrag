# 单仓库网络检索与前端缺引用提示（2026-09-23）

## 实现和配置

- 本仓库的 `direct_web.py` 可直连 Tavily 或 SearXNG，返回来源URL、当次获取时间、逐字材料、独立快照及其SHA。`retrieval_mode=web` 和 `hybrid` 不再必须存在旁边的 SearchReader 源码目录；旧 `searchreader` 提供方仍为软件默认，避免改变当前服务。
- 自动联网只交给配置的模型选择器。内置提供方沿用 SearchReader 的材料优先二值分类协议；模型端点或严格 `true/false` 输出不可用时显式失败，不用关键词兜底。用户要开箱强制联网仍需配置一个实际搜索提供方和 RWKV 问答模型；本次没有把外部供应商服务或模型权重打包进GitHub仓库。
- 新 `.env.example` 和 `README.md` 说明两种内置提供方及自动模式配置。密钥留在本地配置；网络失败日志仅记错误类型或HTTP状态，不记响应正文或密钥。
- 前端 `answerFormat.ts` 新增“有保存来源、正文没有任何有效引用”的标志，在搜索、历史和Wiki共用的 `CitedAnswer` 中警示。它不改写模型原文、不补引用；缺引用与引用错位仍由模型和人工证据核查解决。
- 后端字面审计另增`missing_valid_citation`，用于后续统计有来源而没有可用编号的运行；只审计是否有编号，不验证事实是否被支持。增加后本机API已重启，健康接口返回200，MongoDB与OpenSearch均正常；旧历史原文没有重写。
