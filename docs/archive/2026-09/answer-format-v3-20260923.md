# 答案展示转换层 V3

用户要求在前端过滤RWKV编造的来源编号与明显复读。实现位于[前端转换函数](../../../llamaindex-retrieval/web/src/answerFormat.ts)和搜索、历史、Wiki共用的答案组件。它核对来源编号实际映射、`[资料 N]`格式及长片段重复：96个连续字符出现两次，或32个连续字符出现三次，都会隐藏主答案并给出提示。模型原文、API `answer`、证据和历史运行收据均保持原样，仍可展开核对。被隐藏的答案不会作为新一轮对话历史，也不会在历史列表摘要中继续显示。

45项前端测试、TypeScript与Vite构建通过。本机18440已切到`answer-format-20260923-v3`；实际页面返回新的JS，结果页和API/Mongo/OpenSearch检查成功，[部署收据](../../../artifacts/answer-format-20260923/DEPLOYMENT-v3.json)绑定脚本和结果页哈希。远端模型与后端链路未切换。

使用已完成的24道新GitHub题96份原文及实现者审读做[同批事后核对](../../../artifacts/state-progression-20260923/format-gate-v2/AUDIT.json)：人工判为完整正确的32份均保持显示，人工判错的64份中54份被拦下、10份仍可见。V1格式门在同批原文上拦下48份错误、留下16份错误；V2增加双次长段复读检测。**这是针对已观察答案的显示行为核对，不是独立检出率或模型语义质量证明。** 真实错误即使引用编号合法、输出不重复，仍可能穿过格式门。要提高答案可靠性，必须继续解决阅读、关系绑定与证据支持，而不能只靠过滤显示。
