# 上下文与state边界

当前RAG通过BM25检索和Reader证据选择减少Writer输入。历史、任务列表和证据是应用数据；各模型调用之间没有自动延续完整RWKV动态state，也没有已验证的跨文档state合并。

训练state是模型开始读取prompt前的初始状态，并不包含某份文档的阅读记忆。换问题、历史或证据时必须重新读取对应输入；不能把不同前缀产生的状态当成可互换缓存。

输入预算需要按实际模板和tokenizer计算，不能用原文字符数或模型文件名代替。StateTune训练对超预算样本拒绝执行，不截断正确答案；本轮配置上限8192，Writer实际最长训练序列5012 tokens，不能据此声称验证了所有8192-token输入。

早期8K/16K/32K外部API探针与不同后端数值对照是历史实验，不代表当前服务的硬上限。完整条件和原始输出见[实验归档](artifacts.md)中的同路径旧版文档。当前训练经验见[StateTune总结](statetune-experience.md)。
